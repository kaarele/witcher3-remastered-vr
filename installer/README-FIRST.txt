Witcher 3 Remastered VR - install in one step
1. Close the game. Open "Install (Linux)" or "Install (Windows)" in this folder. It finds the game, backs up
   your saves, copies the mod and sets everything up. Linux: if it opens as text, right-click > Run, or run
   installer/install.sh in a terminal. Windows may ask "Run anyway": the installer only uses files in this folder.
2. Start your VR runtime (WiVRn, SteamVR, ...), then the game. To remove the mod: "Uninstall (Linux/Windows)".
